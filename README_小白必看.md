# 平遥2026观影日历｜微信小程序源码（小白版）

这是一个可以直接导入微信开发者工具的原生微信小程序。

## 你需要准备

1. 一台电脑（Windows 或 Mac）
2. 微信开发者工具
3. 一个微信账号
4. 本文件夹里的全部源码

## 从 0 开始运行

### 第一步：安装微信开发者工具

打开微信开发者工具官方网站：
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

下载与你电脑系统对应的版本并安装。

### 第二步：解压本 ZIP

把这个 ZIP 解压到电脑，例如：

桌面/平遥2026观影日历/

注意：
真正需要导入微信开发者工具的是里面包含 `app.json` 的那个文件夹。

### 第三步：打开微信开发者工具

打开后：

1. 点击「+」或「导入项目」
2. 项目目录选择本文件夹
3. AppID：
   - 如果你只是想在自己电脑上运行和测试，可以选择「测试号 / 使用测试 AppID」（具体按钮名称可能随开发者工具版本略有不同）
   - 如果你已经有自己的小程序 AppID，就填写自己的 AppID
4. 项目名称可以填写：平遥2026观影日历
5. 点击「导入」

### 第四步：看到小程序页面

正常情况下，左侧模拟器会出现：

- 日期选择
- 电影列表
- 映前 / 映后标签
- 首映 / 主会场等标签
- 按日期查看排片

如果出现页面空白或报错：
先不要改代码，把右侧/下方「控制台」里的红色报错截图发给我，我可以一步一步帮你处理。

## 这个版本目前有什么

- 2026年9月24日—9月30日排片
- 按日期切换
- 映前 / 映后场次优先显示
- 首映、主会场等信息
- 可筛选创作者场、首映、主会场
- 目前使用的是排片数据版本

## 目前还没有做完的部分

「根据你的豆瓣1800部观影记录，按照 20%个人口味 + 50%奖项/电影节履历 + 30%导演/演员热度自动打分」还没有写入这个版本。

原因是豆瓣公开收藏页共有1800条记录，网页分页展示，不能在当前源码里凭空假设已经完成全部1800条的匹配。

## 如果你以后想自己改电影数据

打开：

`data.js`

这里保存排片数据。

不要一开始就改代码逻辑；如果只是改电影、时间、影厅等排片信息，优先改这个文件。

## 给完全不会编程的人

你现在不需要学习 JavaScript 才能先把它跑起来。

第一目标只有一个：

「安装微信开发者工具 → 导入这个文件夹 → 看到小程序页面」。

跑起来之后，再一步一步做：
1. 加入你的个性化电影评分
2. 加入“我的必看 / 可选 / 放弃”
3. 加入冲突排片提醒
4. 加入每天3-4部推荐
5. 最后再考虑发布成真正可以在手机微信里打开的小程序



## v5 观影日历版

这一版的核心目标改为：
1. 首页按日期展示排片；
2. 点击电影查看导演、主创/主演、获奖及电影节履历；
3. 点击“＋”选择当天想看的电影；
4. 生成当天观影日历；
5. 使用微信小程序 Canvas 生成可保存/转发的图片。

注意：图片保存需要用户授权相册权限；“直接转发”是否可用取决于当前微信客户端和基础库对 showShareImageMenu 的支持。


## v6 交互调整

根据需求新增/调整：
- 点选电影右侧「＋」后变成「−」，再次点击取消选择；
- 已选电影卡片增加选中状态；
- 电影详情不再单独依赖隐藏弹窗：排片卡片本身可点击查看详情，详情包含时间、影厅、单元、导演、主创/主演、获奖/电影节履历；
- 任何缺失字段直接不展示，不显示“暂未补充”等占位文字；
- 详情页也可以直接选择/取消选择。


## v7 交互修正版

本版本修复了两个问题：
1. 之前 WXML 直接调用 isSelected(item) 会导致选择状态无法可靠刷新；现在由 JS 预先计算 selected 字段，所以 ＋ / − 会稳定切换。
2. 电影详情改为直接展开在当天排片卡片下方，不再使用独立详情弹窗/页面。

奖项信息字段拆成“电影节入围 / 展映”和“奖项 / 提名 / 获奖”。只有已经有公开资料支持的信息才展示；没有可靠资料的字段直接不显示。
