# 平遥 2026 · 观影日历 H5

这是“平遥2026观影日历”小程序的纯网页备用版。无需微信小程序工程即可运行。

## 本地测试
直接双击 `index.html` 在部分浏览器可能因本地文件安全策略导致海报/Canvas加载失败；建议用一个静态文件服务器测试，例如在本目录运行：

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080/`。

## 部署
将整个文件夹上传到支持静态网站托管的服务即可。不要删除 `assets/` 或各个 `.js` 数据文件。

## 功能
- 9/24—9/30 日期切换
- 电影排片与大师·对话
- 详情展开
- 加入/取消个人日程
- localStorage 按日期保存选择
- 智能安排：电影节履历60% + 主创关注度30% + 映前映后10%
- 智能安排自动避开大师·对话时间
- 官方购票链接复制
- 今日 / 全程观影日历生成
- 复古平遥视觉分享图
- 手机浏览器保存图片；支持 Web Share 的浏览器可直接分享图片

## 注意
这是静态网页版本，不包含登录、后台和服务器数据。用户选择只保存在自己的浏览器 localStorage 中。

## v9 校对说明
本版本根据用户提供的《平遥国际电影展 9.24–9.30 排片总表》校对排片数据：补入遗漏场次，并修正部分场次时间/影厅信息。大师·对话信息沿用已校正版。
